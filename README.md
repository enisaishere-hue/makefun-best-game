Lumen Tide — Keeper of the Last Light: a glowing arena-survival game. You are Luma, a lantern wisp on a dark reef. Swim with WASD, dash through danger with Space, fire light bolts automatically, collect Light Motes to level up and pick one of three upgrades, charge your Nova, and survive ten nights — the last one ends with the Abyssal Maw. Win by banishing the Maw; lose when your light goes out. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and press Space to play. No build step, no network requests: the game is plain static files under `game/`.
